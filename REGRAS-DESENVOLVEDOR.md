# Regras do Desenvolvedor

- Respeitar a arquitetura do projeto.
- Não substituir a estrutura por outra sem aprovação.
- Não apagar materiais fornecidos pelo proprietário.
- Criar branches para funcionalidades e correções.
- Abrir Pull Request para alterações relevantes.
- Nunca versionar `.env`, senhas, tokens, certificados ou chaves privadas.
- Documentar novas dependências e mudanças estruturais.
