# Arquitetura — NG Doce Duo

## Objetivo
Manter uma estrutura previsível, organizada e fácil de manter.

## Fluxo recomendado
Frontend → serviços/API → backend → banco de dados.

Os arquivos de conteúdo fornecidos pelo proprietário ficam em `assets/` e não devem ser misturados ao código da aplicação.
